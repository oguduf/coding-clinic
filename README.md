# coding-clinic

Realistic, enterprise-grade problems suitable for Fortune 500 environments. Each challenge is designed as a standalone, reusable automation/scripting task. Consultants should implement the solution (Python, Bash/Shell, Ansible, Terraform, JavaScript/Node.js, PowerShell, Go, etc.), package it cleanly, and push it to a public or private GitHub repository with:

● Clear README (problem statement, architecture, prerequisites, usage, examples)
● Well-structured code + tests where applicable
● Configuration examples/sample inputs
● Security considerations and idempotency notes
● CI checks (linting, basic validation)
